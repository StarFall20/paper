The main result connects fixed choice menus and prediction correction to whether a finite logit estimate exists. A 32-plus-32 row example holds the predictor, weight, labelled choices and sample sizes fixed, with identical local derivatives through third order and three distinct existence outcomes. The general construction matches any specified finite order. Independent checks used exact arithmetic on 30 cases up to order 33 and original menus on 1,960 Swissmetro fit points and 7,536 food-choice fit points.
