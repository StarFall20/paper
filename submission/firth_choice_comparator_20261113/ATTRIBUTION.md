# Sources and reuse

Public attribute support derives from Cheng Lu, Mengxin Wang, Dennis Zhang and Heng Zhang, Generative Augmented Inference, ICML 2026, PMLR 306, 81730–81751, https://proceedings.mlr.press/v306/lu26am.html . The source repository is https://github.com/ChengLu1999/generative-augmented-inference at d18717206867c7a12ff470879a0dd5d488b300c2. Its README assigns CC BY 4.0 to datasets: https://creativecommons.org/licenses/by/4.0/ . This package keeps the first 1200 profile differences and a fitted coefficient used as the simulation parameter, with transformations and hashes recorded in evidence/inputs/provenance.json. Human outcome rows, raw pickle files and participant identifiers are omitted. Baseline records are earlier generated model experiments, not human survey rows.

Firth estimation and its finite-estimate property are established prior work. The new Python implementation is independently written from the estimator formula; no source from the authors' GPL brglm2 repository is copied or executed. The pinned reading units and publication sources are recorded in evidence/prior_scope.md. This archive assigns no additional license on behalf of an unidentified author or rights holder.
