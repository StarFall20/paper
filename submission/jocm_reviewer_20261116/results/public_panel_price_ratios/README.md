# 食品 DCE 的价格方向与属性价格等值

本轮使用已经核对的 16000 条方法记录和 15418 组有限系数，检查有限拟合之后的经济解释。没有新增拟合、参与者、独立模型队列或 AI 答卷。[二次分析方案](plan.json)在计算价格等值分布前固定；原有预测表现和价格方向汇总已经存在，这不是对原研究事先注册的新结局。

核心结果限制了可以作出的应用主张。15418 个可得拟合中，15417 个价格系数为负，只有 1 个为正，出现在五人预算的聚类选权重方法。二十人和四十人预算下全部方法均有 500 个有限拟合，Bere 价格等值与普通标签 MNL 较接近。五人预算下各方法分布更宽，直接 ridge 也出现较大的比值。结果不支持“校正普遍造成异常价格方向或破坏经济解释”的说法。

## 单位与解释

[原始公开数据](https://zenodo.org/records/15420092)的 metadata 第 104 行将价格定义为每包 250 克短饼的英镑售价。属性模型用原价格除以十，因此每 GBP 的效用导数是 price 系数除以十。一个单位属性对比的价格等值为 −10×属性系数／price 系数；Bere 指标对应加入 Bere flour 与不加入的对比。所有八个非价格属性都按同一规则计算。恰为零的分母不定义比值，没有另外设置可删去不利结果的近零阈值。

这是一组边际条件 logit 的系数比值。负价格条件下的摘要保留有限拟合和负价格两个分母；全部非零分母的代数比值另表保存，包括价格为正的情形。正价格在本模型的成本负效用解释下具有非标准方向，不能据此把受访者判成无效。全部 500 次分配都保留在可得性表中。

每种方法都固定使用同一批来源、同一预测器和同一评价组。all_human 方法另使用相同的 100 位固定训练参与者。这里的百分位只描述标签分配变化，既不是总体 WTP 分布，也不是置信区间；固定训练样本的抽样不确定性没有被重新抽取。不同方法的有限样本目标和标签成本按原方案保留，没有已知真实 WTP 可用来计算估计误差。

## 复现与验证

reference 只包含已经公开备份过的派生系数和方法记录、原独立核对结果及公开单位说明，不含原始答卷、受访者编号、工作簿或项目报告 PDF。数据与派生成果的来源为 Chen、Mzek 与 Piras（2025），Zenodo 15420092，CC-BY-4.0；这份补充计算保留相应归属。

使用 NumPy 2.5.3 和 pandas 2.2.3 计算，无需重新下载原始数据或拟合模型：

```sh
python verify_package.py
python analysis/compute_ratios.py --out regenerated/results
python analysis/verify_ratios.py --out regenerated/verification
```

独立核对器默认检查包内 results。完整重跑请在另一份包副本中将计算输出指定为该副本的 results，再执行核对器，以保留原始完成结果。

[另写的核对程序](analysis/verify_ratios.py)用 60 位 Decimal 先换算每 GBP 的价格导数，再解补偿方程，独立重建 123344 个属性比值、32 个可得性摘要、512 个属性摘要和 64 个配对摘要。均值使用 math.fsum，百分位使用有理概率的次序统计量插值，不导入主计算代码或任何模型拟合例程。最大按量级缩放的差异小于 4×10⁻¹⁵；[核对记录](verification/verification.json)绑定输入和输出。这里指不同计算实现的核对，不表示外部同行评审。
