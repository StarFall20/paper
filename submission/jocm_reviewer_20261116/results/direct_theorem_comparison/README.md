# 主定理与最近存在性理论的直接比较

本轮把“是否只是套用已有公式”分成两个可以核对的问题，得到不同结论：**最近的单行损失分类公式不能直接代入；一般高斯锥相交定理则确实是现成工具。** 本稿可争取的增量是特定补偿 Logit 的显式边界计算及其后果，不能把通用相变机制重新称为创新。

## 已完成的实质检查

同一平衡 Gaussian 模型中固定预测器、数据分布和辅助／标签样本比，只把权重从 1/4 改为 3/4。两边的标签行都分别严格递增或递减，辅助行都强制增长，所有行都严格凸。经区间计算和另一套原始距离积分核对，存在性边界分别为 **0.6624600373** 和 **0.4841966704**。在维度／标签比 0.55 处，两者得到相反的严格存在性极限。

这说明只保留单行损失分类会丢失本问题的关键信息。Koriyama–Bellec 的已发表定理要求每行下确界有限；补偿标签行下确界为负无穷。其证明用其他行的有限下确界约束逃逸方向，这一步在此不能使用。该比较没有把原定理当作不满足条件的“失败基线”，也没有声称它的结论有误。完整推导见[比较证明](proof.md)，精确边界见[结果](results/population_pair.json)。

同时用现有附录 B5 的原始行数据，在两个均小于 1 的权重下作了分数运算核对：0.5 有唯一有限解，0.6 的衰退成本为 −1/80。两边的分类、完整曲率秩和参考 Hessian 相同。它是既有设计例子的复核，不新增受访者或模拟样本。该有限例子沿原有路径改变预测，固定预测器的区别由前面的总体例子承担。

## 收紧创新定位与文献归属

最接近的通用公式不直接适用，不能据此推出“所有已有理论都无法处理”。条件化后的高斯核与固定锥相交，直接使用已有运动学定理。新的工作量集中在补偿区间的统计维度极限、两个优化变量的一致控制，以及存在性、协方差和概率损失的严格分离。逐项归属见[依赖比较](theorem_dependencies.md)。

另发现一个可删减的证明段落：当前 G3 关于高斯核非零相交会进入相对内部的结论，已有 Götze 等的 Corollary 5.6 直接给出。文稿应明确引用并压缩重复证明。[拟修改文本](proposed_revision.md)已给出，保持主定理和现有结果不变。当前已审 Word 尚未改动，避免正文、附录、数学对象与排版版本不同步。

这一轮排除了一个具体的直接代入质疑，并进一步剥离已有理论。它没有产生第二套方法或新的通用几何理论。**是否构成足够的期刊贡献，仍须结合该显式结果相对其他具体论文的优先性和选择分析价值判断。** 当前不认定达到投稿线。

## 复现与来源

[计划](plan.json)在两项新边界计算前固定参数。[计算程序](calculate.py)用 160 位 Arb 和全局强凹上界；[单独实现的核查](verify_independently.py)使用原始距离公式、256 位矩及 SciPy 数值积分，并以 Fraction 检查有限例子。两种区间实现使用同一 Arb 库；SciPy 是另一数值引擎，其误差估计不冒充区间证明。没有导入生产计算程序，没有新模型拟合或 Monte Carlo 抽样。

安装[依赖](requirements.txt)后，在新目录运行 `python calculate.py`、`python verify_independently.py`。生产程序拒绝覆盖已存在的总体边界。之后可用 `python verify_package.py`核对交付文件及来源哈希。独立目录重跑记录见[重跑核对](replay_verification.json)，全部科学输出逐字节相同。

本轮查阅了正式 ICML 2025 本地全文的指定段落，并在线核对发布页、arXiv v3、Götze 等 2020、Han–Ren v2、Amelunxen 等 2014 的相关结果。没有声称通读所有论文。共执行 7 条普通网页查询，Scopus、Google Scholar、WOS 均为 0；[来源记录](sources_and_search.json)保留具体范围。原文 PDF 和私人问卷均不在备份包内。
