# 补偿 Logit 的局部导数可以完全相同，有限估计结局仍可相反

在同一份带截距的二元选择设计中，固定真人数据和辅助属性，调整补偿权重。对任意预先指定的有限阶数，都可以让拟合目标在参考点的全部局部导数逐项相同。使用两组共用的缩放预测器后，逐条参考得分、Hessian 和按同一规则计算的经验协方差也完全相同。权重取 \(1/4,1/2,3/4\) 时，解分别为**唯一有限解、有限下确界无法达到、无下界**。同一份真人数据的普通 Logit 有唯一有限解。 [证明](proof.md)

把预测器固定为同一个有信息的线性概率规则时，三个权重仍有相同的目标 Taylor 多项式和相同的三种存在性结局。固定规则下各条参考得分会随权重变动。行得分逐条相同的结论对应缩放预测器。

## 存在性余量能相差多少

令 \(K\) 表示匹配的最高偶次矩为 \(2K\)。正斜率方向上，两个权重的衰退成本差的最紧上确界等于**权重差乘以 \(|x|\) 的最佳一致多项式近似误差**。这项近似对偶已有文献。本文构造把它转成补偿选择模型的存在性余量，并在相同的真人数据上给出三种结局。 [Cai 与 Low](https://arxiv.org/pdf/1105.3039)

| 完全相同的最高局部导数阶数 | 有理构造的 \(1/4\) 权重正斜率余量 | \(3/4\) 权重正斜率余量 |
| ---: | ---: | ---: |
| 3 | 0.031250 | −0.031250 |
| 9 | 0.008672 | −0.008672 |
| 17 | 0.004367 | −0.004367 |
| 25 | 0.002915 | −0.002915 |

表中取接近最佳近似界的构造。另有一组简明的有理构造检查到 **33 阶**。这些结果用分数直接核验衰退符号。第 25 阶的理论最大权重间差异约在 **0.005830 至 0.005972** 之间，两个权重分别为 \(1/4\) 和 \(3/4\)。高阶矩配对会压缩仍无法分辨的余量。近极端设计的权重通过重复记录可以严格实现，所需记录数可能很大。结果属于数学构造，食品与交通实验的观察频率来自各自的独立实证。

## 复核与复现

[分析计划](plan.json)固定 8 个任意阶数构造和 7 个近极端构造。生成程序用线性规划寻找候选接触点，独立脚本用分数核对矩、得分、Hessian、协方差与衰退成本，并用高精度二分求有限斜率。连续区间上的误差界通过精确网格计算和区间插值误差界验证。 [构造数据](results/designs.json) · [验证结果](results/verification.json)
