# Sources and reuse

The independent analysis scripts in this package were written for the present study. No downloaded research script is executed. Mathematical and estimator sources are cited in the manuscript. This archive does not assign an additional software license on behalf of an unidentified author or rights holder.

Categorical prediction correction is established in Fan etal.2024,multiPPI++ (published Section3.2 and AppendixA.2–A.3). Common coefficient MNL correction is explicit in Ye and Yoganarasimhan2026,arXiv2604.17267v2,AppendixB.2 ExampleB.4 and B.3 EquationB.6. These inspected constructions are prior work. Tan and Bellec2023 uses a different class coefficient matrix and imposes existence in Assumption2.4;its official PDF model and discussion were inspected. The manuscript's Theorem3 and AppendixF calculate the specified compensated menu boundary. The existing fixed-dimensional control-variate criterion supplies the menu experiment's reference power;it is not a new tuning rule. The ordinary perfect-label and wedge reductions are also classical. Actual [reading scope](reports/menu/reading_scope.json) and unsuccessful database access are retained.

The new menu scientific sources are byte-identical to the recorded research scripts,as checked in [source hashes](results/menu/source_hashes.json). The interruption inputs and exact initial phase sources are preserved for the recorded numerical checks. Regeneration or resuming a checkpoint adds no statistical replications. The publication asset builder uses only the completed aggregates and retains all displayed cells.


Public numeric inputs belong to Cheng Lu, Mengxin Wang, Dennis Zhang and Heng Zhang, Generative Augmented Inference, ICML 2026, PMLR 306, 81730–81751: https://proceedings.mlr.press/v306/lu26am.html . The pinned source repository is https://github.com/ChengLu1999/generative-augmented-inference at d18717206867c7a12ff470879a0dd5d488b300c2. Its README states MIT for code and CC BY 4.0 for datasets. Source URLs, sizes and Git blob identifiers are in reports/public_conjoint_audit_20261109/source_manifest.json. Downloading those files retains their original README and LICENSE. The present archive distributes aggregates and download metadata, without redistributing the numeric pickle files.

PPI power tuning and the one step construction derive from Angelopoulos, Duchi and Zrnic, PPI++, arXiv:2311.01453v2. Generic separation/support LPs and conic kinematics are established methods, attributed in the manuscript. The original reference code was inspected and independently implemented, not copied into this archive.

Sablica,Hornik and Rusch2026 (arXiv:2610.08100v1) give categorical-likelihood existence and separation geometry. The inspected model definition,Theorem1 and Sections4.1–4.2 reinforce that generic LP detection is established. The present corrected objective uses signed residual correction;the main calculation is its explicit two-sample existence boundary. This source check does not establish exhaustive priority.

The independent-training cost diagnostic is a prespecified simulation with disjoint training/correction labels and the same total label union for direct human baselines. The packaged source changes only the original workspace import path. Original and packaged script hashes and the complete replay comparison are in `results/training_budget_source_adaptation.json`. No prediction error or label-efficiency superiority is claimed from that diagnostic.

The added DY comparator is the established zero-prior pseudo-response estimator of Sterzinger and Kosmidis,with fitted-intercept related theory by Sterzinger2026. Its dimension rule and definition were inspected in the authors' pinned [MDYPL repository](https://github.com/psterzinger/MDYPL/tree/1f68c36ba78d512c312ec4c7fcf929e1fc405bbe). The Python implementation is independently written from the estimator formula. External R code is not copied or executed. The added noisy-label citation records Natarajan etal.2013 as prior lineage for unbiased convex loss correction.

Correlated teacher/fitted feature spaces are established in Loureiro etal.2021. Cross prediction and fixed target-dimensional learned-predictor inference are established in Zrnic–Candès2024. Their pinned [cross-ppi repository](https://github.com/tijana-zrnic/cross-ppi/tree/3516654bcd5a2c29d67d73861944312d1554ac7d) was inspected through its README and notebook inventory;no external notebook was copied or run. The present index constraint,conditional linear-score existence argument and matched calibrated examples were written for the compensated loss. [The source-scope record](reports/public_conjoint_audit_20261109/aligned_prediction_prior_scope_20261110.md) distinguishes these claims from generic Gaussian rotation,calibration and training algorithms.
