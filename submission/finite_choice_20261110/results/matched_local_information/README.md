# 相同参考点信息下的有限解反例

本轮从稿件已有的得分保持路径出发，构造并核验了一个更严格的有限设计对照：**相同数据、相同参考点、相同逐行修正得分、相同完整 Hessian 与经验协方差，仍可对应有限唯一解和无界目标。** 模型仍是原有两样本补偿 Logit，含一个待估截距和一个属性系数。

| 对照项 | 权重 1/2 | 权重 1 |
|---|---|---|
| 参考点 | (0,0) | (0,0) |
| 目标在参考点的值 | log 2 | log 2 |
| 参考点梯度 | (0,-29/80) | (0,-29/80) |
| 完整 Hessian | I/4 | I/4 |
| 参考点经验 sandwich | diag(4057/2800,3/112) | 相同 |
| 从参考点作一次 Newton 更新 | (0,29/20) | 相同 |
| 正向衰退斜率 | 1/80 | -9/80 |
| 全局估计结果 | 唯一有限解，属性系数约 3.67677 | 目标无界 |

精确分界权重为 **11/20**；等于该值时下确界有限但无法在有限系数处取得。结论由[解析推导](derivation.md)承担。[精确分数计算](results/exact_information.json)检查设计矩、逐行得分和矩阵恒等式；[另行编写的 90 位核对程序](verification/verification.json)直接重算原始补偿损失，没有使用主程序的合并得分公式。两个有限根的梯度残差小于 1e-85。数值射线只是解析衰退结论的核对。

这加强了稿件原有受控比较：观察 Hessian 也无法填补参考点信息与全局存在性的差别。它没有新增框架或估计器；没有把经典凸支撑、分离、局部与全局的区别算成原创。设计中的 2 条标签和 8 条辅助剖面是数学构造，不是真人答卷，不计作新增独立模拟样本。参考点经验 sandwich 也不是实际抽样方差或有效置信区间。

[先行研究对照](prior_and_value_assessment.md)补读了 Li–Cai（2026）的指定结果，并追踪其非平方损失参考文献。广义的“准确率不代表下游价值”已有研究，不能用于本稿的原创性主张。当前更具体的目标是补偿 Logit 中匹配得分与曲率后的全局存在性。尚未确认该构造的全球优先性，也未据此认定达到投稿门槛。
