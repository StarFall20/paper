# 本轮增量及投稿价值审查

本轮核验得到一个可保留的加强：在同一有限补偿 Logit 设计里，参考点逐行得分、完整 Hessian 和完整经验 sandwich 可同时保持相同，而目标从有限唯一解变为无界。该构造含待估截距，预测均在开区间内，使用同一数据和同一损失家族。它比已有标量例子多控制了完整的观测曲率。它仍是对论文主线的受控反例，没有增加第二套理论。

## 近邻原文带来的约束

[Li 与 Cai（2026）](https://arxiv.org/html/2611.08959v1)已研究原始预测误差 Gram 无法决定线性学生风险，并区分原始与学习后的误差几何。实际读取包括 §3、§4.1–4.2、B.1–B.2、B.6、E.1–E.2 和 §9 的相关单元。其结果直接限制任何宽泛的“预测准确率不代表下游价值”原创主张。本稿应聚焦补偿目标的存在性，并明确相同的对象是什么。

其共同线性学习算子假设、平方风险分解及正则化学生优化，与当前未惩罚补偿 Logit 的全局极小值问题不同。这是结果范围判断，不能推出本稿已获优先权。其文章对任意适当损失的开放问题，也不能替代对更早分类理论的核对。

沿其参考文献实际追踪了 [Mulgund–Pabbaraju（2025）](https://proceedings.mlr.press/v267/mulgund25a.html)与 [Xu 等（2026）](https://proceedings.mlr.press/v306/xu26by.html)。PMLR 正式摘要明确已有非平方损失和交叉熵结果。实际读取的预印本单元为前者 v2 的 §3.4、Theorem 4.1、Corollary 4.2、Theorem 4.3，以及后者 v3 的 §3 和 Theorem 4.1。它们分别研究 Bregman/KL 近似投影的风险关系、教师与学生联合随机性下的风险差。这些工作使“我们首次推广到非线性分类”也失去可辩护性。当前对照关注的对象应始终是原有两样本补偿损失的有限系数极小值；未声称正式 PDF 与所读预印本逐项相同。

两篇综述本轮用于定位文献与术语，实际仅筛读指定介绍与高维/存在性匹配段落，没有当作原始定理证据。Koriyama–Bellec v3 的 Assumption 2.5 再次核到逐行下确界可积条件；这一不适用点此前已记录，不能作为新的原创证据。

## 对目前投稿价值的影响

这个新构造可以回答一个更具体的质疑：早先的不同存在性是否只反映参考点 Hessian 不同？本例在两个待估参数上把 Hessian 也固定了。它同时说明相同的一次 Newton 更新不能判定目标是否有全局极小值。这不否定单步估计在相应条件下的用途。

论文对选择分析的可保留含义是：若目标是估计既定、未惩罚的补偿效用参数，就需要区分参考点效率诊断、优化器返回值与目标的全局可估计性。经典支撑检查可以执行这个判别；该检查本身不是新方法。增长维度的显式边界仍承担主要理论工作，公开选择数据审计与预测损失仍承担实际影响的证据。

这个反例没有证明事件在常见 DCE 中高发。它没有比较福利或支付意愿，没有证明一般预测优势，也没有验证问卷招募随机化。其两端权重是既定比较，不能表述为方差最优选择规则的失败。既有随机模拟、标签预算与公开数据结果保持原范围。一个更干净的反例提高可解释性，不能自动提高实际重要性。
