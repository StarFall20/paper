# 真实 DCE 的权重可估计范围与新增先例核查

这次跟进得到两个具体结论。第一，低标签预测辅助 Bradley–Terry 的近分离已有直接先例；一般预测概率向量和修正得分也有既有框架，均不能承担本文独立创新。第二，对同一批真实 DCE 划分计算权重可估计范围，确实能增加有限拟合数量，但强行进入可估计范围仍可能显著损害预测。当前候选贡献继续限定为特定补偿 Logit 的显式存在性边界及受控后果。

## 新增实证计算

继续使用 Chen、Mzek、Piras（2025）的 [RADIANT 数据](https://zenodo.org/records/15420092)，许可 CC BY 4.0。沿用原 298 位完整受访者、100 人训练／60 人评价／138 人修正池的隔离划分、冻结预测器、全部 500 次嵌套分配和原属性编码。没有招募、生成或重新训练。两千个划分不是两千批新人。

[方案](plan.json)在阅读之前的实证结果之后、计算本次权重范围之前写明；不称作预注册。对每个划分，线性规划最大化闭区间 [0,1] 内的可行权重上端 c，再检查 c/2 是否严格处于支撑内部。[推导与适用范围](proof_and_scope.md)说明该计算来自经典凸支撑，不能把可行端点直接解释为有限最优解。

两项事先写入本次方案的规则分别取 c/2，以及把原方差权重投影到 [0.1c,0.9c]。区间比例是固定的计算约定，没有用评价集选择。未认证到正权重内部的划分明确保留，评价时退回原标签组 ridge。未计算置信区间。

| 标签人数 | 原单位权重有限数 | 原半权重有限数 | 两项跟进规则各自有限数 | 数值零或近零上端 |
| --- | ---: | ---: | ---: | ---: |
| 5 | 356/500 | 426/500 | 443/500 | 57/500 |
| 10 | 479/500 | 498/500 | 499/500 | 1/500 |
| 20 | 500/500 | 500/500 | 500/500 | 0/500 |
| 40 | 500/500 | 500/500 | 500/500 | 0/500 |

数值零状态使用 10⁻¹⁰ 的上端阈值，不据此声称精确算术下所有任意小的正权重均不可行。其余 1,942 个划分的中点与投影权重均有严格内部见证，3,884 组系数均通过原始得分检查。预算 20/40 人的上端全部被 [0,1] 的范围截在 1，不能解释为已求得该范围之外的最大权重。

## 可估计性与预测

下表的损失覆盖全部 500 次分配，不可得时使用同一标签组 ridge。越小越好。评价组与训练、修正组分离；标准误只描述固定数据上的分配随机性。

| 标签人数 | c/2 规则 | 投影方差权重 | 标签组 ridge | 使用训练标签的直接真人 MNL |
| --- | ---: | ---: | ---: | ---: |
| 5 | 1.0635 | 1.3043 | 0.9081 | 0.6287 |
| 10 | 0.7718 | 0.7837 | 0.7857 | 0.6291 |
| 20 | 0.6975 | 0.6982 | 0.7427 | 0.6299 |
| 40 | 0.6712 | 0.6711 | 0.7252 | 0.6315 |

5 人组投影规则相对标签组 ridge 的平均超额损失为 0.3962，分配 MCSE 为 0.0490；c/2 规则为 0.1554，MCSE 为 0.0260。10 人组 c/2 相对 ridge 的差为 −0.01395，MCSE 为 0.00298。四个预算中，将预测器训练所用的 100 人标签计入后，直接真人 MNL 的预测均更好。完整结果保留全部八种原基线、条件损失和全分配回退比较，没有按优势挑选表格。

这些结果使建议更具体：先审计目标和权重范围，再分别评价预测与训练成本。它们不支持把“有限解更多”改写成“预测更优”，也不支持把这两项规则包装成新的独立估计理论。

随后增加了[保留零权重的事后对照](cap_only_amendment.json)，避免把强制正权重的代价误归于上界截断。它仅在可行上端为正时取 min(原权重,0.9c)，零权重保持为零；数值零上端保留原不可得状态及同样的 ridge 回退。四个预算有限数为 353、495、500、500；全分配损失为 1.1644、0.7951、0.6991、0.6712，与原聚类选权重十分接近。5 人组仅新增一项有限拟合，另 11 个原外部目标仍处于数值零上端组，不能宣称截权重可普遍修复估计。

这个对照是看到前两项规则结果后制定的，单独保存全部 2,000 条记录，没有改写原方案。仅 32 个改变权重的内部目标重新拟合，1,816 组系数在目标完全相同时复用已有核验结果；[另一项原始逐题核验](verification_cap_only/verification.json)检查了全部 1,848 组可得系数、内部概率见证和预测指标。新增主计算共拟合 3,916 次，另核验 1,816 组复用系数，不能把全部 6,000 条策略记录称为新拟合。

## 来源与独立核验

[检索记录](literature_followup.json)保存六组实际 Google Scholar 查询。17 条相变交叉结果和 4 条 Logit 相变结果全部做题录／片段筛查，宽检索只读首十条。新全文比较覆盖 TC-PPI、DiPPI 等指定章节。[12 项精确分数计算](results/framework_embedding.json)核对修正得分对一般合并得分框架的代入关系。

Scopus 完成用户学校登录和再次机构访问回跳后仍显示 Preview，未出现文献检索入口。本轮 Scopus 文献查询为零；这不能推出学校没有购买权限，也没有把 Preview 页当成文献搜索结果。之前的八组 WOS 查询保持原记录。

[独立核验](verification/verification.json)检查全部 2,000 个原始逐题矩约束与未截顶上端的对偶方向、4,000 条策略记录、3,884 组系数及其评价指标；另外按实际预算／上端／内部状态分层重建 29 个完整逐题 LP。最大矩误差低于 3.8×10⁻¹³，最大得分误差低于 5.3×10⁻⁹，独立 LP 上端差低于 1.7×10⁻¹³。它共享读取和分组函数，未导入主程序的范围 LP、压缩目标、拟合或评价函数。

首次核验后发现两项原始 LP 上端为约 −10⁻¹³ 的浮点越界值。[修正记录](bound_normalization.json)保留原值、初次核验和文件指纹，把报告权重规范到约定的 [0,1] 区间，并完整保留原始上端列。没有改变任何系数或评价汇总。见证数据采用无损压缩，保留全部值。当前独立核验针对最终文件。

## 复现与当前稿件

需要 numpy、scipy、pandas、openpyxl 和 threadpoolctl。原始工作簿不随包分发；下载后先核对固定指纹。所有脚本均由本项目编写，下载源数据不执行任何代码。

```sh
python analysis/fetch_source.py --out local_inputs/COSCBB.xlsx
python analysis/run_frontier.py --input local_inputs/COSCBB.xlsx --out regenerated/results
python analysis/verify_frontier.py --input local_inputs/COSCBB.xlsx --results regenerated/results --out regenerated/verification
python analysis/run_cap_only.py --input local_inputs/COSCBB.xlsx --frontiers regenerated/results --out regenerated/cap_only
python analysis/verify_cap_only.py --input local_inputs/COSCBB.xlsx --frontiers regenerated/results --results regenerated/cap_only --out regenerated/verification_cap_only
python verify_package.py
```

只重验保存数值时，将独立核验命令的 `--results` 改为 `results`，并指定新的 `--out`。`verify_package.py` 仅检查打包文件与已保存证据，不重新拟合。当前已审 Word 保持上一轮版本；[待整合文本](proposed_manuscript_revision.md)给出必须补引的最近先例和本次结果。此报告增强了真实设计决策证据，也收缩了宽泛创新主张，尚不构成独立评审或投稿门槛认证。
