# Attribution

The scalar covariance weight and one-step formula are established PPI++ methods: Angelopoulos, Duchi and Zrnic, arXiv:2311.01453v2, Section 6.2. Generic Newton updates and variance tuning are prior. This audit adds no theoretical novelty claim. Official repository commits and static observations are in source_scope.json; upstream code is not copied or executed.

The finite attribute support comes from Lu, Wang, Zhang and Zhang, Generative Augmented Inference, repository commit d18717206867c7a12ff470879a0dd5d488b300c2. The pinned README specifies MIT code and CC-BY-4.0 data; reference/source_manifest.json records the files. Frozen parameter vectors are retained simulation parameters, not asserted structural truths of observed human behavior. Outcomes and proxy labels in this audit reconstruct earlier simulations.

The six inherited helper sources are unchanged copies from the existing reproduction release. They are retained for provenance and import closure. User questionnaire observations, participant identifiers, credentials and downloaded article full texts are excluded.
