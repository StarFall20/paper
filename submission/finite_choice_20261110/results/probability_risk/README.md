# 有限解恢复与概率损失

2026年11月12日。本补充沿用当前论文的补偿Logit目标，检查一个直接影响应用的后果：正权重趋近于零可以恢复有限估计，同时使概率预测损失发散。有限解的存在边界、系数增长和新样本概率损失在同一目标内连接。经典分离、最大间隔和正则化极限均保留文献归属。

## 理论结果及其条件

[完整推导](theory.md)给出适用于实际设计的系数范数下界，明确包含梯度残差和近似分离方向的负边际质量。它可用于核对数值输出，未要求预测器独立于当前设计。

在正文Theorem 2的二元高斯模型中，设维度比例严格位于普通Logit边界与正权重上包络之间。任意严格为正、可以依赖数据且依概率趋于零的权重，使有限唯一根以概率趋于一存在；其范数至少按log(1/权重)增长。对有限真实效用信号，新的高斯属性行上的人工总体对数损失随之依概率发散。已知高斯最大间隔定理提供正的人类分离间隔，本文的有限设计不等式把该间隔接到同一个补偿估计器上。未给权重添加独立性或收敛速率要求。

零信号时有明确的概率含义：Brier损失趋于0.5，真实概率0.5对应的最优值为0.25；分类错误率始终为0.5。该结论没有建立一般的最佳权重，也没有比较完整GMM或惩罚估计器的风险。有限网格上的损失可以不单调。

## 公开选择数据上的固定预测路径

[公开方案](public_plan.json)在拟合这组路径前固定：使用既有500次排列的前60次，每次20条人工标签和1180条辅助属性，两种原预测程序，六个权重0.5、0.1、0.02、0.005、0.001、0.0002。每次分配的预测只拟合一次并跨权重冻结，原有类别缺失回退保留。公开数据共4605行，后3405行用于评价；其标签没有进入本轮拟合。五行区组沿用原研究脚本约定，没有已核实的受访者标识，不能声称人群外推或人员完全不重叠。

## 已知真值模拟

[模拟方案](gaussian_plan.json)含200个独立模型抽样，人工标签数80和160各100次，辅助数等于人工数，噪声斜率数为floor(0.6m)，另估计一个截距和一个高斯属性斜率。所有真实系数为零。固定预测为翻转概率0.25的二元代理后验，未生成测试选择；新行对数损失和Brier损失由一维正态积分计算。

下表每行仅对该行有数值有限解的抽样计算损失，不同权重的分母不同。全部六个权重、配对差和模拟均值的Monte Carlo误差见[已核对汇总](verified_summary/all_path_summary_verified.csv)与[配对表](verified_summary/all_paired_summary_verified.csv)。

在0.5与0.0002共同有解的39和43次抽样中，平均对数损失差分别为36.5512（Monte Carlo标准误4.2569）和34.2667（2.4899）。最初从0.5降至0.1时，同一共同样本的平均差分别为−1.2676和−0.1604；多数抽样与中位数仍变差。均值受重尾影响，故同时报告中位数、逐项增减计数和共同分母。理论结论针对趋近零的极限，不推出每次降权都恶化。

## 数值复核与保留记录

全部1920条计划记录保留，1401个数值有限拟合、519个支撑外目标，最终没有未决支撑状态。独立实现重算1401个系数处的梯度、损失及系数下界；389个不同坐标的端点线性规划覆盖两类预测的全部路径，固定预测下的强制性嵌套覆盖中间权重。这里没有声称重新运行1920个独立支撑程序。

公开数据和模拟的最大梯度／权重分别为9.75e−8和9.51e−8。梯度的两种实现最大差约1.6e−15，系数下界无违反。有限支撑和满秩条件证明目标的有限唯一极小点存在；数值损失针对保留系数计算。小梯度本身没有被当成系数距离的统一误差证书。

初次独立核对发现两个不同问题。第一，模拟的5个未决支撑状态和1个边界近似状态，均由严格负衰退方向确认处于支撑外。第二，原高斯积分在6个大系数拟合中遗漏窄的sigmoid导数峰，最大Brier差0.0016813。改用显式峰值分段后，与独立的logit坐标积分一致：对数损失最大差1.14e−13、Brier差5.56e−17。原CSV、系数、初次程序和失败记录全部保留；汇总使用verification_final中的修正评价。修正没有重拟合选择模型。
