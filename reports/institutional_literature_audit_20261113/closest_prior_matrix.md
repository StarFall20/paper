# 最近邻结果对照

这是限定范围的原文对照记录，非全球优先权证书。每行标明实际读取深度。

| 文献与入口 | 已有内容及阅读依据 | 当前稿件可保留的区别与限制 |
|---|---|---|
| [Geyer 2009](https://www.stat.umn.edu/geyer/gdor/)，Albert–Anderson 1984 | 凸支撑、衰退方向和logit存在性；经典原文前期核查 | Proposition 1是具体修正矩的应用，不主张新几何判别原理 |
| [Amelunxen等2014](https://doi.org/10.1093/imaiai/iau005) | 统计维度与随机锥相交的相变工具；前期定理核查 | Theorem 1调用此工具，增量需落在补偿区间剖面的显式计算及后果 |
| [Götze等，v2](https://arxiv.org/abs/1911.04184v2) | Theorem 3.1、Lemma 5.1已涵盖一般高斯像吸收步骤；前期原文核查 | 不能把一般高斯吸收或相对内部转化重新命名为新原理 |
| [Han–Ren 2026，v2](https://arxiv.org/html/2212.05545v2) | 本轮读取Theorems 1.1、1.3及logit应用2.1：一般锥投影、原像及零信号锥约束MLE阈值 | 参数约束锥与本文修正残差锥不同；一般投影工具仍属前人。本文的指定分布计算和受控比较需承担贡献 |

| [Sablica等2026，v1](https://arxiv.org/html/2610.08100v1) | 已核对Theorems 1、4及§4.1：类别似然的重叠、可估计空间唯一性与LP检测 | 该先行结果应在有限设计审计处引用，不能只列在文后；已补引 |
| [PPI++正式版](https://doi.org/10.1214/26-AOAS2215)、[已读预印本v2](https://arxiv.org/abs/2311.01453v2) | PPI估计、协方差与功率调节为既有方法。正式发表信息本轮由机构索引核实；正式全文受人工验证限制 | 本文不主张PPI目标或方差权重为新方法；正式版本新增内容仍须进一步核对 |
