## 创新性客观判断

最值得保留的结果是：在明确的两样本修正 logit 目标中，给出包含辅助样本比例、预测分布、效用信号和拟合常数的存在边界；再构造局部得分与完整常规协方差相同、有限解存在概率却趋向相反极限的比较。由这条边界推导的正权重上包络、恢复有限根后的概率损失后果，以及沿既有方差权重增加辅助数据的反例，形成同一问题内的连续论证。

下列内容已有直接前驱，不能各自计为独立创新：凸支撑内部判别、分离方向、LP检测、统计维度定位高斯相变、PPI控制变量、条件校准恒等式、Firth或DY消除分离、一般消失正则化与间隔极限。新发现的 Han–Ren 原文进一步确认，广义高斯投影与锥约束 logit 的相变已有系统理论。稿件已补引并把这些工具的归属写清。[最近邻差异表](closest_prior_matrix.md)按结果层面区分现有内容与待主张的增量。

“不是缝合”需要由研究问题、假设、推导与证据之间的关系说明。当前主线在同一个既有目标内研究有限估计，结构上具有连贯性。多加一个扩展、缩写或模拟不构成独立性证据。审稿人仍可能认为显式边界只是一般理论的特例；必须让匹配信息后的存在差异及其实际分析后果承担主要贡献。不能以“某个旧定理假设不满足”直接推出新结果足够重要。

Firth 的20标签 MSE为1.949426，150标签 MSE为0.108848；两种设定均返回500个有限拟合。20标签覆盖率0.999455伴随平均区间宽度5.939401，应解释为宽区间下的覆盖表现。Firth 使用期望信息矩阵的逆；其他方法保留各自的协方差约定。一个样本存在两个经核查的局部极小值，所有返回值均保留；没有数值全局最优证书。本文不能据这些结果宣称新方法普遍优于成熟惩罚估计。

## 尚有实质性不足

1. **应用价值仍需收紧。** 高斯剩余属性、独立两样本和冻结预测器是理论条件。普通DCE的离散属性、受访者重复任务和跨拟合不能直接套用相变公式。公开数据的精确审计解决给定目标是否存在，尚未建立具有独立人群验证的预测或福利估计优势。
2. **反例与可实施方案要分开。** 保持真值得分的 oracle 路径是理论比较；已观测参考系数的路径保持参考得分。二者不能互换。已知正效用尺度也不等于估计了现实中未知的误差尺度。
3. **文献追踪尚未封口。** 正式 PPI++ 全文、少数新增近邻全文和后续引用链仍待核查。没有因某个检索式未命中就判定原创。
4. **常规协方差不是高维推断保证。** 本文研究存在性；所匹配的固定维度常规协方差不能直接解释为比例维度下所有区间均有效。
5. **篇幅需要取舍。** 主体已经有充分长度。优先压缩重复解释，将延伸放入附录；增加页数不能弥补应用影响或定理增量不足。
