# PPI++ 作者研究分支与近邻文献核对

在已有的 16 个公开疫苗选择案例和 4 个解析设计上重跑了 PPI++ 作者研究分支，并记录点估计、区间和单步路径。此前的 68 次点估计逐条复现，另增加 68 次调用。代码由[作者主页的 Code 链接](https://tijana-zrnic.github.io/)定位，固定为[公开提交 363265dd](https://github.com/aangelopoulos/ppi_py/tree/363265dd97919b47e185b9a0b069dcf5463e79d4)。该提交和正式期刊 Supplement B 的文件同一性尚待确认。上游九个 Python 源文件在执行前后均核对 Git 内容哈希。

八个内部案例的单步点估计用独立的行级梯度和 Hessian 运算重建，最大差异为 (1.34\times10^{-15})。研究分支的区间接口在选中单步选项时仍进行了最终一次完整拟合，区间中点与该拟合值逐一匹配。八个内部案例中有六个使用负调整权重。论文的凸性与支撑结论限定在权重区间 ([0,1])，这些负权重调用只用于核对代码行为。核对目标为预选案例，结果无法估计常见应用中的失效率或区间覆盖率。

解析设计的精确临界权重是 (11/20)。在该浮点输入上，底层求解器报告成功，最大得分残差约 (5.11\times10^{-15})，区间端点均数值有限。斜率区间宽约 (7.06\times10^{13})，精确目标的下确界有限且不取到。该例把报告优化成功与最优解确实存在区分开来。复跑采用原核对的容差和上限，记录不代表其他配置下的结果。

固定分支的 WebGPT notebook 用截距和标准化的两回答长度差解释偏好票，并比较经典、PPI 和 PPI++ 区间。两份 logistic 模拟 notebook 比较调权设置，其中一份显式调用单步区间。以静态阅读核对实验范围，未运行上游 notebook。复跑的估计和区间来自同一固定提交的公开接口。

## 近邻文献与检索覆盖

- **Chen、Bai 和 Zhu，2026 年 11 月 6 日版，§4.2 和补充 §S3.9。** 他们以平方 GMM 矩条件和协方差校准研究有限样本风险。分组 logistic 定理先限制每组的三个二项结果中有一次或两次成功，给出该事件内的有限估计与风险增量。零信号下，该事件的概率为 ((3/4)^d)。本文检查线性校正损失能否在任意已观测菜单上达到有限最优值，并计算比例维度下的临界条件。两篇都研究有限样本 logistic，目标函数、条件和结论各有具体区别。[预印本正文与补充](https://arxiv.org/html/2610.21837v2#S4.SS2)
- **Song、Kluger、Parikh 和 Gu，2026 年 11 月 13 日，§3.2、§4 和 §6。** 文中汇总有限样本效率、预测质量和标签覆盖的诊断，并讨论高斯均值问题的有限样本边界。其诊断关注抽样与推断条件，本文的检验关注已观测选择设计所定义的优化目标是否达到有限最小值。[发表版本](https://hdsr.mitpress.mit.edu/pub/dwrc1xcp/release/2)
- **Tan 和 Zrnic，2026 年 8 月 21 日版。** 他们从历史任务的可交换性出发，为合成数据应用构造推断保证。公共意见调查是其应用之一。其可交换性框架针对跨任务校准，本文使用同一拟合任务中的真人选择与预测菜单。[预印本](https://arxiv.org/abs/2606.13629v2)

本轮公开检索覆盖 prediction-powered logistic 的有限最优、无界、分离和单步，以及离散选择和 conjoint 的预测辅助估计。机构 Web of Science 标签显示登录错误 90013，未获得本轮新增记录。11 月 13 日已存档的九组 Web of Science 检索与既有 Google Scholar 筛选继续保留。订阅版 Scopus 的检索和正式 PPI++ 附件仍待核对。当前结论仅覆盖已取得的版本、代码与记录。
