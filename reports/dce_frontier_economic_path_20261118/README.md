# 逼近补偿 Logit 的权重上限会改变什么

**在真实 DCE 中，有限解可以持续存在，预测却会随权重逼近上限迅速恶化。** 本次把前一版只判断有限解是否存在的分析，推进到计算系数路径、价格等价和留出损失。五人组的 87 个内部上限划分中，从上限的 50% 移到 90%，留出预测对数损失中位数从 **1.3075 升到 2.2208**，逐划分损失差的中位数为 **+0.8067**。同预算、单位权重仍可估计的 356 个划分，中位数从 0.9004 升到 0.9264。每个点仍有经过数值核验的有限解。

## 系数、价格等价和选择判断

[推导](proof.md)给出横穿单一边界面时的精确渐近形式。系数在垂直于边界面的方向以 `log(1/(c−λ))` 发散，乘数由拟合菜单中最小正效用差给出。平行于边界面的系数收敛到只保留并列最优备选的条件模型。两部分共同决定价格系数、经济比率和留出损失。留出损失的对数增长系数等于留出真实选择相对于该方向最优备选的平均效用差，除以最小正差。107 个实证边界的这个系数均为正。

全部 7,536 个计划点的价格系数均为负。102 个内部上限的边界方向具有负价格分量，Bere 价格等价收敛到两个方向分量之比。另 5 个方向的价格和 Bere 分量同时为零，其比率由条件模型的两个有限系数决定，这 5 个条件价格仍为负。到最近测试点，五人和十人组的 Bere 价格等价中位数分别为 £0.397 和 £0.250，半权重分别为 £0.467 和 £1.177。五人组 £2.50 判断的 6 个改变有 3 个由接受变为拒绝、3 个反向，十人组 1 个改变由拒绝变为接受。全部 £0、£2.50、£5.00 的判断、切换方向以及同一划分的标签组 ridge 和计入训练标签的真人 MNL 比较见[汇总](path_summary.json)。这些是同其他条件不变时的拟合效用比较，不能推为实际选择或总体支付意愿。

## 可计算的改进与核验

只用最小正差计算首项，在最靠近的计划点仍有明显尾部误差。另作[事后检查](diagnostics/gap_spectrum_plan.json)，固定条件模型的切向系数，用整个差值分布求一条标量方程。最近点的法向系数绝对误差第 95 百分位从 **39.21 降到 0.0812**。离上限相对距离 0.1 时，标量近似的预测损失绝对误差中位数仍为 **0.9192**。设计给出的误差上界在最近点对 106/107 个划分成立，半权重和九成权重处均不满足该充分条件。这个计算适用于诊断边界附近的数值行为，不能替代完整拟合或用作自动选权重规则。 [完整近似结果](results_gap_spectrum/summary.json)

独立程序重算了 107 个未压缩原题线性规划，并用有理属性差与模素数秩下界核对 107 个边界面的秩。最大上端差小于 1.7×10⁻¹³，最大原逐题得分差小于 3.8×10⁻¹³。全部留出损失和价格判断重新计算。最靠近上限点最初有 8 项由于法向曲率很小而无法通过数值检查。用精确效用差和原目标的等价坐标稳定求解后，原逐题得分、相对法向余量和选择结果全部通过。原失败记录和改动已保留。 [初次核验](diagnostics/initial_numerical_check.json) · [独立核验](verification/verification.json)

## 对稿件的增量

指数族的方向、条件面和边界上的模型已有理论。本节的具体增量是对同一补偿选择损失推导逼近**正权重上限**的速度和可计算后果，并用全部实际进入该情形的划分验证。它让选择建模读者能估计有限拟合何时已经产生极差的概率预测。数据没有出现广泛的价格符号反转，£2.50 比较大多稳定。结果支持把概率校准、可估计性和经济比率各自报告。近上限展开、普通指数族几何与现有预测修正方法的归属见[文献核查](literature_scope.json)。当前正式稿仍使用已经核验的版本，本证据供下一轮精简整合。原创性和投稿价值仍待按主定理逐项审视。

```sh
python analysis/check_gap_spectrum.py --input local_inputs/COSCBB.xlsx --frontier ../upstream/frontier --results regenerated/path --out regenerated/gap_spectrum
python verify_package.py
```
