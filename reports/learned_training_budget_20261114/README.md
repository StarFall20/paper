# 训练预算与创新点复核

本轮补上了一个具体理论缺口：给出完全由训练标签计算的预测器，并证明它满足稿件原先假设的训练收敛条件。新增实验继续研究同一个预测校正 Logit 目标。当前61页正文及已经检查的 Word 文件未改动，新增证据先独立核验，避免在贡献判断之前继续加长正文。

## 新增的可检验结论

总人工标签和辅助属性行数均固定。把更多人工标签用于训练，会减少最终校正估计可用的标签。预测器本身更准确，不保证整个估计流程更容易获得有限解。

在总标签维度比0.3、辅助行数等于总人工标签数的模型中，训练份额从25%增加到50%，训练预测器的极限误分率由33.45%降到29.29%。全部正权重的存在上界分别为0.477758与0.510186；最终校正所需的维度比同时由0.4升至0.6，第二种分配超过了上界。这里的上界由现有定理计算，数值经过另一种正态积分及联合方程复核，并非有理区间形式的数值证明。

有限样本检验固定160条模拟人工选择标签、160行辅助属性和48个属性斜率。40个标签用于训练时，500次抽样中419次存在某个正权重可取得有限估计；80个用于训练时降到90次。把全部160个标签直接用于人工 Logit，两个独立条件分别有485次和480次有限估计。训练份额之间使用独立抽样，各条件内部的权重与人工基线共享同一批数据，不能把跨份额差异称为配对实验。

全权重检查覆盖了代理信息情形的全部4000个原有模拟样本。其中1080个找到显式正权重，并对原始目标确认内点；2920个具有严格人工分离和负校正衰退方向，阻断所有正权重。最小严格人工间隔与最小负成本间隔均超过0.0000141。独立重建后的人工衰退值为零，原始目标恒等式误差低于8×10⁻¹⁶。这个检查复用既有样本，不增加4000次独立重复。

## 模型和证明具体补了什么

训练器采用经典的“标签符号乘以属性后取平均”，同时对额外观测代理计算同样的系数。它没有访问真实效用系数或真实选择概率。高斯条件分布与大数定律给出信号方向、噪声范数及代理系数的显式极限，再代入原稿的条件训练定理。这样不再仅写“假设训练参数收敛”，而是给出一个已证明满足条件的学习规则。

另给出一个由既有极限公式导出的必要预算界，依赖预测绝对误差和 Brier 风险。它能排除极小的校正标签预算，但比完整上界弱；在50%训练份额的例子里，不能单靠这个粗界得出失败结论。用估计误差替代总体误差时，还需要不确定性分析。

模型保留额外代理，是为了维持真实的信息增益通道。只用拟合属性的负对照也完整保留。在正确设定的人工 Logit 下，这类预测器的真实参数处得分与人工残差正交，常规方差最优权重退到零。因此，该负对照的正权重表现不能用来宣传校正估计的效率收益。

## 完成的核验

两组各8个条件、每条件500次模拟，共8000个独立模型抽样和32000条方法判断。全部条件、零频率与不利结果均保留。独立核验重建全部样本，检查20752个原始目标负方向、3897个人工严格分离方向及960个预先规定的替代区间程序。96个总体边界条件另用不同积分规则复核，最大差异低于1.6×10⁻¹⁴。32个全权重极限条件也有独立半直线积分复核。

最初的独立包缺少一个间接依赖，停止于生成前；补充权重检查的一条断言曾误把“使用全部标签的人工基线”纳入“只用剩余标签的校正目标”的嵌套条件。两项均已修正并留存记录，原始主实验结果未改。接近数值零的弱方向进一步改为有严格正间隔的方向，分类没有变化。

## 客观创新判断

经典训练均值、信号与高斯噪声分解、旋转、分离程序和原稿已有的正权重上界均有明确归因。新读的 Saglietti 与 Zdeborova 论文已经使用 Hebb 均值及其高斯表示；本轮没有把这些重新命名为创新。它对主稿的价值，是把外生或条件化预测器的论证落实为可训练、计入全部标签成本的实例，并说明更准确的预测器如何与估计失败共存。

本轮主要提升理论适用条件的可验证性和预算解释。核心原创性仍需由“特定校正目标的显式边界、匹配得分与协方差下的相反存在性、恢复有限解的概率损失代价”承担。增加模拟数量和训练案例本身不足以证明达到投稿门槛。
