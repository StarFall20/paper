# 公开食品选择中的菜单频数与有限估计

复查 RADIANT 和 Swissmetro 原有 96 组固定标签划分。每组的 8 个辅助样本各有 64 名受访者。两份辅助样本的菜单集合相同，指可选项身份和归一到首个可选项的属性差完全相等。使用档案的原编码逐项比较，属性数值无舍入。 [原划分与预测说明](../fixed_label_auxiliary_design_20261118/README.md)

RADIANT 的每份辅助样本都完整覆盖同样的 34 种菜单。每个权重各有 1,344 个辅助样本对，所有样本对的菜单频数均不同。沿用包含受访者特征的预测器时，单位权重有 74 对从有限跨到无下界，权重 0.5 有 7 对。按原始任务概率重新核验了这些状态。Swissmetro 的原编码菜单没有完全相同的辅助样本对。

进一步固定每种菜单的辅助预测。对每种菜单，把冻结预测器在整个校正池给出的预测向量取均值。同一菜单在所有辅助样本中使用这一向量，真人样本及其预测仍保持固定。每份辅助样本有 384 个任务，覆盖相同的 34 种菜单。现在辅助样本之间只剩菜单频数的差别。

| 权重 | 有限配置 | 无下界配置 | 有限和无下界配对 | 出现跨越的标签组 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 322/384 | 62/384 | 70/1,344 | 5/48 |
| 0.5 | 352/384 | 32/384 | 0/1,344 | 0/48 |

单位权重的原有 74 个跨越配对中，65 对保留跨越。另有 5 对在同菜单预测设定下跨越。权重 0.5 的 32 个无下界配置来自 4 个固定标签组，每组的 8 个辅助样本均无下界。全部 768 个配置分别使用原始任务行和合并后的菜单权重核验。该结果说明，现有食品实验支持单位权重下的纯频数机制。更低权重的三种状态由附录 J 的数学反例给出。两份数据的固定划分共享受访者，计数只描述本次档案复查。 [逐配置结果](results.json) · [复现代码](verify.py)

用投稿包解压后的 `Reproduction_Materials` 和其中指定的两份公开输入运行：

```sh
python verify.py --archive /path/to/Reproduction_Materials --food-data /path/to/COSCBB.xlsx --swiss-data /path/to/swissmetro.dat --out results_copy.json
```
