# 整菜单模型补测与贡献取舍

补测于2026年11月15日启动，11月16日继续核验。原文整菜单实验只检验有限解频率；二元模型的参数与预测结果不足以覆盖这个范围。本轮复用全部原有菜单样本，补上该缺口。

## 核验结果

1000组既有高斯菜单样本、六组标签/维度条件、五种方法，共15000条记录全部保留。原有9000个支撑状态全部重现。11018个数值有限拟合均按原始目标复核，未决项为零。另用独立的大积分检查67个拟合，包含20个最大系数范数；同一批积分不是新的受访者或训练样本。

最能说明原论断限度的是原图已经展示的80标签、52噪声属性条件：修正模型有269/500次有限解，普通MLE有32/500，单位功率为0/500。在共同269次可用拟合中，修正、人类ridge、预测标签合并的对数损失中位数分别为1.8524、1.6837、1.0207。

不能把269次条件均值与ridge的全部500次均值直接当作公平差值。采用明确的ridge后备规则后，修正策略在全部500次上的平均损失为2.264907，直接ridge为1.696402；配对差为0.568505，模拟标准误为0.128705。概率损失越低越好。

进一步按“恢复了普通MLE没有的有限解”分层，新增的237次可解拟合平均损失为2.893638，同237次ridge为1.713726。这是看到主结果后的次级描述；六个条件、四种可解分层的24行全部保留。它没有被包装成预先指定的新假设检验。

## 对论文方向的影响

“提高有限解出现率，进而形成更实用的新估计方法”这一推进不能成立。该模型在当前实验中的主要价值是揭示修正目标的存在边界与局部效率计算之间的差异。有限解、系数精度、概率预测和区间覆盖必须分别交代。

仍可保留的候选贡献是具体修正目标的高维边界，以及匹配局部信息仍有相反存在事件的受控结论。一般凸支撑、正则化、分离、控制变量和普通风险取舍都是已有理论。新增菜单补测进一步约束应用主张，本身不构成新的原创理论。

对照也有明确范围：ridge使用原有固定惩罚，没有调到风险最优；预测标签合并改变目标；功率是已有常规方差公式在已知总体下的参考值。它们不是任意调参后的最强基线。这组结果足以否定本稿当前设置中的普遍预测优势，不能推广为所有修正方法的排名。

当前决定是把论文收束为一篇存在性与后果的研究，撤去任何从整菜单可解率直接跳到实际预测用途的表述。正式PPI++及附件差异、具体结果优先权与充分的期刊价值仍待核实，暂不宣布达到投稿门槛。
