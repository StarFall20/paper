# 完整GMM近邻定理与同设计比较

2026年11月12日。本轮重新阅读CC-PPI的具体目标、全局充分条件及实现约定，把已有全局证书与本文的补偿损失存在边界作了逐项比较。推导和计算已进入正文第3.2节、讨论及附录B6。

## 核实后的界线

[CC-PPI原文](https://arxiv.org/html/2610.21837v2)第2.1—2.3节给出完整矩与协方差构造，附录S3.10命题S3.3给出全局有限解的充分条件。其条件同时保证人工Logit在一个球内有零得分点；证明是把人工Hessian的下界沿半径积分。因此，人工Logit已经分离的设计不满足这一证书。这是该组充分条件的适用界线，不能推广成完整GMM一律需要人工MLE存在。

本轮沿用附录B5的同一标量设计和路径终点。真人属性为2与4、选择均为1，辅助属性均为1；对应预测为25/44与1/2。单位权重补偿损失有严格负衰退方向，人工MLE也不存在有限解。采用明确给定的零参考和已有的中心化协方差加岭规则后，完整GMM目标有一个有限点严格低于正、负无穷处的两个极限。分数运算据此证明它存在有限全局最小值。

这项比较采用已有完整GMM目标。它没有复制CC-PPI的全部初始估计、谱保护更新与最终拟合过程，没有提出新的估计器，也没有比较预测误差。它把正文的结论明确限定为指定补偿损失的存在边界，避免从一种经验目标失效推断所有预测辅助方法都失效。

## 计算证据

[精确记录](results/complete_gmm_exact_comparison.json)使用有理数计算正定协方差、逆矩阵、有限值及两个极限，不依赖优化器。有限值为43618624129/38838705425，两个极限为1225/977与10729/977。有限值严格更低。

[独立核对](results/verification/complete_gmm_independent_verification.json)从原始数组重建协方差、得分和目标，最大矩阵误差4.45e-16、极限误差1.78e-15。另保留[7个数值初值的全部返回](results/verification/numerical_returns.csv)：它们均显示成功且梯度小，但4个返回的目标值高于已知有限点，因而不是全局解。这个结果说明具体停止信息的限度；全局存在结论由精确不等式证明。

4941组中心与半径检查用于核对证书公式，不承担全体参数的证明。所有中心都无法满足条件的结论来自[向外得分推导](derivation.md)。

```sh
python analysis/certify_complete_gmm_comparison.py --out regenerated/complete_gmm
python analysis/verify_complete_gmm_comparison.py --certificate regenerated/complete_gmm/complete_gmm_exact_comparison.json --out regenerated/complete_gmm/verification
```

两条命令从仓库根目录运行，也随当前投稿复现包提供。输入是已保留的确定性例子，无新问卷、AI答卷或购买数据。原公开数据和大规模模拟未改变。

## 对投稿判断的影响

“一阶等价而有限样本不同”“存在全局有限解诊断”及“完整矩目标”均有明确前人工作，不能承担本文的独立创新主张。核心候选贡献继续集中在指定补偿目标的显式比例维度边界、所有正权重的共同上界以及同一目标族中的严格比较。与一般M估计理论的区别仍需按实际行损失与假设解释，不能靠改名成立。

Fuh等人的多项选择论文仅核实了出版方摘要，OpenReview标题线索尚无可读官方正文。期刊作者指南再次返回403，浏览器读取也未成功；Scopus与Scholar系统检索未完成。当前材料不能声称完成全部近邻排除或认证达到投稿门槛。后续实质工作继续围绕定理重合与选择建模价值展开。
