# 官方接口诊断与价格等值已整合

[完整稿](../../submission/finite_choice_20261110/manuscript/paper.docx)与[主文阅读版](../../submission/finite_choice_20261110/manuscript/main_text.docx)已统一来源与结果。第 4.2 节和附录 C10 纳入固定官方 ppi_py 版本的 68 次接口调用。选定的 8 个单位权重外部目标均返回数值数组，底层优化器均报告失败；正常对照和精确边界案例同时保留。边界案例说明优化器成功也不能证明有限极小值存在。这些是有意选择的诊断案例，不能推断一般失效率。
