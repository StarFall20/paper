# 固定辅助菜单时的可行权重上限

用 RADIANT 原有的 48 个固定真人标签组和 384 个辅助抽样复核附录 J。每组比较使用同一批真人选择和真人侧预测。辅助样本都包含相同的 34 种菜单及每种菜单固定的预测概率，各有 384 个选择任务。组内仅改变辅助菜单频数。 [原始数据](https://doi.org/10.5281/zenodo.15420092) · [原分组与预测核验](../public_common_menu_diagnostics_20261120/README.md)

在同一个线性规划内解选择概率质量和校正权重，得到最大的可行权重。零权重总可行，因为已观察选择的概率质量可构造目标矩。普通 Logit 有有限解且标签组的属性差满秩时，任一低于上限的权重都具有严格的可行支撑。超过上限后，可以给出令校正损失下降至负无穷的方向。上限本身需要单独判断。

单位权重出现有限解与无下界跨越的 5 个真人组里，4 组的普通 Logit 确认有有限解，对应原有 70 对中的 55 对。其余一组的普通 Logit 分类保持为边界或数值待定。在这 4 组的全部 112 个配对上，下表给出原始任务概率程序确认的跨越数。

| 权重 | 一侧有有限解、另一侧无下界的配对数 |
| --- | ---: |
| 0.75 | 12 |
| 0.90 | 29 |
| 0.95 | 37 |
| 0.99 | 55 |

一组 5 名真人标签的 8 个辅助样本保持同样的菜单和预测。其中一个样本最大可行权重为 0.550779，另有 5 个样本在单位权重仍有有限解。压缩菜单和原始任务行的 384 个上限最大差异约为 1.1×10⁻¹³。62 个低于一的上限各有原始行上的支持方向，另在四个指定权重直接核对 128 个状态。配对共享样本，表中数值描述这些既有划分。 [分析计划](plan.json) · [逐组和逐样本结果](results.json)

下面的复算命令使用投稿包内的 `Reproduction_Materials` 和锁定的 RADIANT 工作簿。

```sh
python verify.py --archive /path/to/Reproduction_Materials --food /path/to/COSCBB.xlsx --out regenerated.json
```
