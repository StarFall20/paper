# 公开真人食品 DCE 已整合

[完整稿](../../submission/finite_choice_20261110/manuscript/paper.docx)与[主文阅读版](../../submission/finite_choice_20261110/manuscript/main_text.docx)已将公开食品 DCE 加入第 4.6 节和附录 C9。使用已发布数据中的 298 位参与者、1788 个选择任务，100 人训练预测模型，60 人固定评价，138 人作为校正池；每人六个任务始终一起分配。四个标签预算、每预算 500 次有限总体分配、八种方法共得到 16000 条方法记录。这些分配不构成新增独立受访者。
