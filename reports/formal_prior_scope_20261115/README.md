## 2 为什么不能只比较逐行损失的定性类别

这里核对一个具体归约：用“递增、递减、强制增长”这三个逐行类别代替修正损失的实际尾部斜率，能否保留有限解事件？

取一个人类标签和一个辅助剖面，两行属性都是截距1，人类选择为0，功率为1/2。两行预测分别为a、b，且都严格在(0,1)内。直接合并同一个原始目标得到

`Q(u) = log(1+exp(u)) + (a-b)u/2`。

| (a,b) | 原始目标 | 有限解情况 |
|---|---|---|
| (1/4,3/4) | softplus(u) − u/4 | 唯一根 u = −log(3) |
| (1/2,1/2) | softplus(u) | 下确界在 u→−∞，没有有限根 |
| (3/4,1/4) | softplus(u) + u/4 | 在 u→−∞ 时无下界 |

三个例子的标签行都严格递增，辅助行都强制增长，属性、标签、功率和秩也相同。标签行的下确界为负无穷；其负尾部可以抵消辅助行的正尾部。有限根事件取决于斜率大小。这个例子说明扩展时必须保留定量补偿，不能只换一个行类别编码。

这不反驳Koriyama–Bellec：它们明确排除了这些无下界行。这个标量例子是经典凸支撑性质的直接核查，也不单独承担本文创新性。增长维度显式边界与匹配信息反例仍须承担实质增量。

[核查源码](../../analysis/verify_compensated_tail_scope.py)用分数运算给出参考答案，再对照现有原目标LP。两种标签、五个功率、五乘五组预测，共250项固定配置，得到100个内部、50个边界和100个外部点，全部一致。目标恒等式最大误差1.78×10⁻¹⁵，有限根最大得分误差5.56×10⁻¹⁷，外部尾部符号误差为零。它不是250次随机实验或新数据。
