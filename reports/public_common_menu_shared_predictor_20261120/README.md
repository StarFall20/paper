# 两组共用菜单预测的敏感性核查

沿用 RADIANT 公开食品选择的 48 个真人标签组和 384 个辅助样本。每个辅助样本都覆盖同样的 34 种菜单。先在既有校正池按菜单算出冻结预测的平均概率。把这个向量同时赋给真人组和辅助组的对应菜单。真人选项记录、辅助任务数量及原有抽样顺序保持固定。 [公开数据](https://doi.org/10.5281/zenodo.15420092) · [原可行权重核验](../public_common_menu_weight_limits_20261120/README.md)

下表覆盖普通 Logit 有限的全部 37 个标签组。每个权重下有 1,036 个组内辅助样本对。配对中一个校正目标有有限解、另一个目标无下界时计一次。

| 权重 | 保留真人侧原预测 | 两组共用每菜单预测 |
| --- | ---: | ---: |
| 0.75 | 28 | 0 |
| 0.90 | 29 | 7 |
| 0.95 | 37 | 7 |
| 0.99 | 55 | 16 |
| 1.00 | 55 | 16 |

前一轮的 0.75 权重结果为 12 对，分母是单位权重出现两类状态的 4 个标签组。全 37 组复算多找到一个在单位权重全为无下界的组，其 0.75 权重另有 16 个跨越配对。两组共用预测的设定在权重 0.90 和 0.95 各有 7 对，均来自同一个 10 人标签组。频数效应的出现范围受预测设定影响。所有计数描述同一档案中的重叠划分。 [逐组结果](results.json)

计算用合并菜单和原始任务分别求两组共用预测下的全部 384 个权重上限。两种预测设定、五个权重和所有能出现跨越的组另核对 400 个原始任务状态。下列命令需要解压后的 `Reproduction_Materials` 及其中指定的同一工作簿。

```sh
python verify.py --archive /path/to/Reproduction_Materials --food /path/to/COSCBB.xlsx --out regenerated.json
```
