# 重复任务比较的边界差已界定

本轮重新处理 11 月 12 日已有的三任务探索模型，没有新建问卷、生成答卷、拟合新估计器或重跑旧 Monte Carlo。已有两组模型匹配完整的真人／预测聚类得分协方差，也把普通 Logit 的临界比例定义为相同。过去约 0.0025 的补偿边界差只有随机积分近似；现在有包含误差预算的确定性界。

| 被界定的量 | 保守界，单位为每位已标注参与者的噪声系数数 |
| --- | --- |
| 模型 A 的补偿临界比例 | 大于 0.719879 |
| 模型 B 的补偿临界比例 | 小于 0.718838 |
| A 与 B 的临界比例差 | 大于 0.001041 |
| 两模型普通真人 Logit 临界比例 | 同为 9/8，即 1.125 |

在比例 719/1000 下，所述渐近模型中 A 的补偿目标以概率趋于一有有限唯一解，B 的目标以概率趋于一位于支撑外部。两者的普通真人 MLE 均在有限侧。两模型单任务分布、每人数目与任务数、逐题预测准确率、完整常规聚类得分协方差及 Hessian 都保持匹配。匹配的是普通 Logit 的概率边界，未声称每个有限样本的真人分离事件相同。

## 增量及其限制

这个结果把早期的数值筛查推进为一个可检查的特定比较，直接研究同一补偿 Logit 目标中的重复任务。一般锥几何、普通相关样本容量、聚类稳健 PPI 方差与选权重均已有归属。它不新增第二套框架。完整推导见[证明](proof.md)，区间数值见[证书](results/enclosure.json)。

差值较小，相关矩阵含很高的相关性，属性仍是指定的 Gaussian 块。它尚不能说明常见 DCE 存在大的实践影响，也不能覆盖混合 Logit 联合似然、部分标注同一人或任意离散菜单。当前正文已有更强的、逐样本保持真人分离事件的正尺度构造。本轮结果需要据新增面板范围与正文长度判断是否值得整合，不能仅凭差异非零宣布达到投稿门槛。完整稿仍为 75 页、阅读稿 31 页，未改动已审 Word 或 808 个先前科学文件。

## 误差如何控制

Arb 用 160 位精度隔离相关矩阵根、正定 Cholesky 主元、全部正态分箱概率／均值及条件方差。128 个一维分箱形成每状态 2097152 个三维节点。四个目标位置、每个四种离散状态，共 33554432 次原始二次目标节点检查。正态两端无界尾箱完整保留。条件 Jensen 与 2-Lipschitz 梯度给出约 0.00049044 的积分余项；每个候选解的原始二次目标和对偶间隙限制投影误差；凹性割线和明确强凹常数限制全尺度最大值。

大规模节点求和采用 IEEE-754 binary64；浮点运算、矩阵与节点近似均有单独预算。此实现采用[明确的浮点运算假设与源级计数](floating_error_audit.md)，没有把它称为全节点 Arb 运算或外部独立证明。见[误差方法](enclosure_method.md)及运行前固定的[检查方案](plan.json)。

## 复现

使用 Python 3.12 和[固定依赖](requirements.txt)，从本目录运行：

```sh
export OPENBLAS_NUM_THREADS=1
export OMP_NUM_THREADS=1
export VECLIB_MAXIMUM_THREADS=1
python prepare_inputs.py --out results/inputs128.json
python evaluate_nodes.py --inputs results/inputs128.json --out results --workers 4
python verify_enclosure.py
```

验证入口会重新构造全部 64 个离散状态的精确概率与二阶矩，检查两组根的端点异号与正定性，并独立重算正态权重、条件方差及最终区间。它不导入节点优化器。节点最优性依据来自原始二次问题的可行点与一阶对偶上界。默认结果中的时间字段仅记录运行耗时，不属于确定性科学输出。
