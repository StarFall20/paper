# Arithmetic assumptions and bounds

The certificate uses Arb for correlation roots, normal cell probabilities and means, conditional-variance remainders, model perturbation bounds and final inequalities. The large product-normal sum uses binary64 NumPy operations under round-to-nearest IEEE-754 arithmetic. Its explicit gamma bounds assume ordinary bounded-length floating dot products, no overflow and finite input values. This arithmetic model is stated in the output; the result is not described as an all-Arb node evaluation.

All evaluation scales are k/64 for k=40,41,42. Box endpoints multiply these dyadics by 1/4 or 3/4 and are exactly representable. Candidate points are clipped coordinatewise to these exact bounds. Inverse matrices only generate candidates. Any finite candidate is admissible, and its original-quadratic primal/dual gap supplies the accuracy bound; no inverse-condition-number assertion is needed.

Arb also checks the leading principal minors of the exact dyadic covariance actually used by NumPy. Its strict positivity establishes concavity of that node quadratic separately from the exact-model Cholesky check. The input and node checks bound each normal coordinate by 8, each model/factor entry by 1, each chosen raw box coordinate by 1/2 and each recomputed residual by 32. Linear entries are bounded by 24. Absolute quadratic terms and the primal/dual expressions are bounded by conservative constants of 128 and 512. Their final evaluation uses fewer than 1024 elementary operations per coordinate or node after clipping. With u=2^-53 and gamma_k=ku/(1-ku), gamma_1024*1024 is below the adopted node guard 2^-30. This guard exceeds the individual linear, quadratic and dual-gap rounding budgets. The observed direct-primal disagreement and dual gaps must also be below it at every reported batch maximum.

Each of four auxiliary states sums n product-normal terms. Constructing weights uses two products, multiplication by the value adds one, and accumulation uses at most n additions per state; grouping and four-state aggregation add bounded work. The adopted 1024 gamma_(8n+256) bound covers these operations using a factor above the absolute weighted-value sum. Four node guards cover point evaluation and primal/dual rounding under total approximate mass below two. The verifier computes these bounds as exact Arb expressions.

Two parameter matrices are distinguished: the exact model Sigma and its float covariance/factor. For each node the error in the optimal value is at most 2||h||||u||||C-C_float||_F+||u||^2||Sigma-Sigma_float||_F. The verifier uses the conservative ||h||<14 and ||u||<1. Arb reconstructs the exact root intervals and the Cholesky factors, so this perturbation is separately enclosed.

The exact conditional normal mean and mass differ slightly from their float nodes and masses. The gradient of the projection-value function is twice its projected point; trace(Sigma)=3 and the bounded box give a uniform Lipschitz bound below six at all used scales. Thus the node approximation contributes at most 6sqrt(3) times the maximum one-coordinate mean error. If the one-coordinate mass L1 error is d, the product-mass error is at most 3d(1+d)^2; a function bound of 256 covers its contribution. Arb recomputes both errors.

Finally, the full normal integration remainder is three times the one-coordinate conditional variance, with both unbounded tail cells included. The concavity secants and the labelled strong-concavity constant 2*(225/256) enclose the maximum over every nonnegative scale. Neither a finite grid maximum nor agreement across random seeds is used as that maximum's certificate.

The operation audit is source-level and internal. A separate all-directed-rounding node replay would strengthen the arithmetic implementation assurance. The certificate records its current assumptions instead of implying such a replay has occurred.
