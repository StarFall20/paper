# 投稿稿原创性与证据可靠性核查

稿件中最有把握的原创主张，是已有预测辅助 Logit 的有限解会随辅助菜单的几何结构改变。正文用具有相同有限阶局部导数的设计证明这一点，并在公开选择数据中固定真人标签复核。重复题目的新结果把机制推进到一个选择实验常见的情形。在单题分布、低维协方差和普通 Logit 的存在概率一致时，同一受访者题目之间的属性相关性仍会改变校正 Logit 的临界点。这些是可以独立对照和复算的定理与实证问题。 [重复题目的证明和模拟](../paired_choice_boundary_20261120/README.md)

## 可靠程度

**数学和计算证据可复核。** 固定菜单的支持判定可以给出原始概率证据或负衰退方向。两题高斯设计的临界差有解析上下界，有限样本的全部 2,280 个校正目标已有另一套原概率写法核对，另有 1,800 个普通 Logit 对照。通常的局部诊断与有限解状态的差别可从公式和代码两边检查。 [证明和复现](../paired_choice_boundary_20261120/README.md)

**真实数据支持机制和适用性。** RADIANT 和 Swissmetro 使用真实公开选择及按受访者划分的留出样本。重复划分共享受访者和设计，结果描述这些已知划分中的状态变化和留出损失。已有同真人预算对照也记录了校正拟合表现较差的情形。数值成功、有限解与预测改善分别有各自的证据，现有结果无法估计新研究中的普遍失效率或证明所有面板的比例边界。 [公开数据核对](../matched_auxiliary_diagnostics_20261119/README.md) · [同预算预测对照](../safe_power_forecast_20261119/README.md)

**投稿判断。** 以有限估计与选择菜单为问题，数学结果和公开数据证据已具备方法论文送同行评审的基础。可主张的增量是上述具体结论及其在选择实验中的后果。优先权评估受检索覆盖和已取得版本限制。订阅版 Scopus 检索、PPI++ 正式附件核对及广覆盖文本相似性筛查仍未完成。WoS 本轮核实了正式文章记录，全文菜单只显示 Google Scholar 查找入口。本地逐字筛查限于附有版本与哈希的 14 份近邻全文。
