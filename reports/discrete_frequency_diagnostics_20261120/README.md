# 相同离散属性水平下的有限解反例

固定预测器、校正权重、80 条真人选择和 144 条辅助记录。真人样本和三组辅助样本都覆盖同样的九个属性组合。只改辅助菜单中四种对称属性差的出现次数，权重固定为 0.5。三组设计在零系数上的目标值、逐行得分、协方差和全部五阶以内导数完全相同。普通真人 Logit 有有限解。

| 辅助对数，按属性差绝对值 0、1、2、3 | 正斜率方向的渐近损失斜率 | 最大可行权重 | 权重 0.5 的结果 |
| --- | ---: | ---: | --- |
| 1、31、1、3 | 1/48 | 18/31 | 唯一有限解 |
| 11、16、7、2 | 0 | 1/2 | 有限下界，无法达到 |
| 21、1、13、1 | −1/48 | 18/41 | 无下界 |

在限定四级、每级出现且总样本量固定的条件下，精确枚举表明这就是与共同局部矩相容的全部三组整数频数。第六阶斜率导数能区分三者。设定 $L$ 个已知且互异的属性差绝对值，至 $2(L-1)$ 阶偶次矩可唯一恢复频数。矩少于这个数量时，允许有理频率并在需要时扩大相同样本量，正频率可以在保持已知矩和同一支撑的前提下改变绝对矩。对特定小样本，整数约束可能缩小相容集合。 [完整推导](supplement_note.md)

相关先例包括 Cai 和 Low 的经典矩匹配、Albert 和 Anderson 的普通 Logit 分离，以及 PPI++ 的校正损失。固定离散支撑和内部校正权重后，仅改变正频率就能改变最优解状态。现有局部诊断仍不能区分这些变化。 [Cai 和 Low](https://doi.org/10.1214/10-AOS849) · [Albert 和 Anderson](https://doi.org/10.1093/biomet/71.1.1) · [PPI++](https://arxiv.org/abs/2311.01453v2)

原始记录使用精确分数验证得分和导数。独立的概率坐标线性规划核对有限、边界和外部三个状态。既有 SciPy 环境可运行：

```sh
python reports/discrete_frequency_diagnostics_20261120/verify.py --out regenerated_discrete_frequency.json
```
