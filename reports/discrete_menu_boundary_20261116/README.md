## 实际增加了什么

[命题推导](theory.md)给出固定正功率下的扩展：独立对称噪声属性在均值零、方差一及高于四阶的有限矩条件下，保留原有严格存在边界。信号仍为高斯。证明使用已有Oymak–Tropp普适性定理，另用收缩概率单纯形处理内部可行性，用经典坐标枢轴论证处理中心化后的离散秩。没有把通用工具或秩论证改名为新理论。

原命题2的逐次得分恒等式是代数关系，平衡模型协方差只使用标准化二阶矩。结合该扩展，同一“局部得分与完整常规协方差相同，存在性极限相反”的构造也覆盖这类独立离散噪声。它加深同一个问题的适用范围，没有拼接第二套估计方法。

命题不覆盖相关效应编码、受可行组合约束的剖面、固定正交或D-efficient数组、受访者面板、任意交叉拟合；也没有将高斯预测风险定理和区间有效性一并推广。额外代理信息与仅由已拟合属性生成的预测仍需区分。

## 全量计算与复核

全部1000组既有独立模型样本被保留。原始高斯噪声分别提供高斯、两水平和等概率三水平属性，在菜单内中心化之前完成转换。选择、预测类别、信号、维度和功率不变。3000组剖面变体是配对变体，不能计作3000组独立样本，更没有增加真人或AI答卷。

保留27000种状态、54个条件单元、36个配对比较；每个标签预算有500组独立样本。80标签、52噪声斜率时，校正模型有限估计数依次为269、274、276；普通MLE为32、30、22；单位功率均为0。全部比较中，离散属性与高斯属性的可解率差最大为3.8个百分点。大样本边界相同不等于有限样本频率相同。

独立核验重现原有9000个高斯状态，检查全部8652个外部分离方向、3287个人类分离方向，以及322个固定正概率下界的可行性程序。未决项、正功率边界项和秩缺失均为零。一次初始核验发现某个已存方向超出名义单位L1约束约1.75e-7；采用明确的正比例归一化并同步缩放间隙，直接复核负衰退值。原方向和主分类未改，初次失败记录保留。
