# Journal of Choice Modelling submission readiness round 32

## Decision

The package is ready for a methods-oriented JOCM submission at the level of a
finite-support design audit. The contribution is the support-complete fibre
certificate and support-repair rule for a coarsened utility representation. The
paper does not claim a new universal lack-of-fit statistic.

## Evidence completed

- Finite theorem and full-menu preservation for multinomial choice.
- Exact 3 x 3 counterexample: candidate variance 4.00, fibre exposure rank 0
  under an endpoint precision design; rank 4 and minimum eigenvalue 0.1222 under
  the support-complete allocation.
- Smart-device quotient check: rank 3 for both maximin and algebraic designs.
- n=800, 500-replication score/LR comparison with 499 randomization draws:
  null 0.062/0.064 and all four non-null conditions 1.000/1.000.
- n=400, 1,000-replication score/LR comparison with 199 draws: null
  0.038/0.043 and all four non-null conditions 1.000/1.000.
- Explicit overlap audit covering conditional-randomization exposure mappings,
  JOCM misspecification tests, residual specification tests, model-discrimination
  design, sufficient dimension reduction, and choice-probability invariance.
- Word manuscript regenerated and all five rendered pages visually checked.
- New round-32 files committed locally and synchronized byte-for-byte to the
  connected GitHub repository.

## Remaining submission risks

The inferential score is equivalent to the saturated fibre alternative on the
declared finite support. The paper therefore depends on the design contribution
being clear to the editor. Hoshino and Yanagi's network-interference exposure
mapping test is a close methodological neighbour and is cited explicitly. A
human-data rejection claim would require a randomized candidate-preserving DCE;
the current Swissmetro analysis is an implementation check and makes no such
claim. Direct Scopus and Google Scholar result pages were not consistently
accessible, so the package records a broad Crossref/publisher/repository/web
search without claiming database-complete priority.

## Package

The submission package contains the Word manuscript, markdown companion, cover
letter, data-availability statement, code, locked CSV outputs, literature audit,
model-validation memo, and round-32 manifest. Raw public data are not
redistributed.
