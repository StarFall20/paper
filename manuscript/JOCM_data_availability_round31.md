# Data availability and reproducibility statement

The analysis code, finite-support design calculations, simulation outputs, manuscript companion, and release manifest are available at https://github.com/StarFall20/paper.

The primary computational checks use generated data and fixed random seeds. The public Swissmetro implementation check uses the canonical purpose-1/3 data; raw public data are not redistributed. The repository records the provenance and retrieval path for that data and reports the exact rows, respondent grouping, model specifications, and path settings used in the check.

The current package is a method-and-design study and does not contain newly collected questionnaire responses. A randomized candidate-preserving DCE would be required for a human-data rejection claim; no such claim is made here.

## AI and software disclosure

The manuscript and code were prepared with computational assistance and then reviewed through deterministic code execution, document rendering, and repository verification. The analysis claims are supported by the saved scripts and outputs. No external AI-generated dataset is used.
