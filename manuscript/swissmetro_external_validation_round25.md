## Purpose

I ran the fibre-conditional diagnostic on the public Swissmetro stated-choice
file to verify that the candidate model, held-out respondent split, complete
menu probability vector, and approximate within-respondent pairing pipeline
work on a real DCE. This is an external observational validation. The file
does not record a randomized assignment between the two members of a
candidate-preserving pair, so it cannot supply the primary paired-DCE
randomization test.

## Data and preprocessing

The official Biogeme file has 10,728 rows. Nine rows have `CHOICE=0` and are
treated as missing; the analysis retains 10,719 rows from 1,191 respondents.
Train, Swissmetro, and car availability flags are kept. The candidate utility
basis uses the common time and cost coordinates divided by 100 and train/car
alternative-specific constants. The raw file, checksum, and preprocessing
record are in `data/provenance_swissmetro_2026-10-07.md`.

## Model run

Each cross-fitting fold estimates the candidate MNL on one respondent split.
The held-out fold is paired within respondent when its full three-alternative
candidate utility vector is within the declared tolerance. The response
contrast is compared with the difference in held-out candidate probabilities;
respondent-level multiplier sign flips provide the reference distribution.
The output contains 12 combinations of three deterministic orientations
(`index`, `time`, and `cost`) and four utility-coordinate tolerances.

At the full-sample descriptive fit, the candidate coefficients are
approximately `(-0.401, 0.280, -1.268, -0.091)` for train ASC, car ASC, time,
and cost. In-sample accuracy is 0.592; the respondent-grouped two-fold
out-of-fold log score is -1.089 and accuracy is 0.592. These numbers are a
baseline fit for the external check, not a new behavioural interpretation of
Swissmetro. The reproducible summary is
`results/swissmetro_model_summary.csv`, generated by
`analysis/swissmetro_model_summary.py`.

## Results

The retained file yields between 126 and 3,540 approximate pairs, covering 60
to 905 respondents depending on tolerance and orientation. The omnibus
p-values vary materially with the observational orientation. For example, at
tolerance 0.05, the p-value is 0.010 for `index`, 0.008 for `time`, and 0.070
for `cost`; at tolerance 0.02 the corresponding values are 0.310, 0.346, and
0.434. This sensitivity is exactly the boundary expected when pair direction
and task matching are reconstructed from an observational file.

## Interpretation

The run establishes that the proposed candidate fitting, full-menu matching,
cross-fitting, and clustered reference calculation can be executed on a real
multinomial DCE. It does not establish the conditional-sufficiency null or
attribute a rejection to omitted utility: orientation and tolerance are not
randomized, and the public file contains no assignment coin. The manuscript
should report this analysis as an external feasibility and stress check while
keeping a purpose-built paired DCE as the empirical gate.
